# Recorded session

Watch the hosted recording:

- [Project Osmos recorded session on YouTube](https://youtu.be/b5K9Eo41HrI?si=1WBMphbUmy21YpMp)

The repository stores the URL in [`osmos-demo-recording.url`](osmos-demo-recording.url) rather than copying the video binary. On Windows, open the `.url` file to launch the recording in the default browser. On other platforms, use the link above or open the `.url` file in a text editor and copy the `URL=` value.

## How to use the recording

1. Keep the [presentation](../presentation/) open while watching.
2. Pause before each demo and prepare the prerequisites listed in the corresponding [demo runbook](../demos/).
3. Compare the conversation order to the two prompt patterns in [`prompts/README.md`](../prompts/README.md).
4. Record product/UI differences caused by preview changes rather than silently changing the reproduction notes.
5. Capture the final plan, generated artifacts, validation evidence, and reset steps from your own run.

The repository intentionally does not download or redistribute the YouTube-hosted video.
