Microsoft Fabric Engineering Enablement

Project Osmos + Fabric Skills Setup

A clean, repeatable Windows setup for GitHub Copilot CLI and VS Code. This guide limits the environment to Project Osmos and Microsoft Fabric Skills while preserving the terminal, search, and subagent capabilities required for successful operation.

Jennifer Ratten

Target operating state

  • Execution: GitHub Copilot CLI launched from a dedicated Osmos workspace.
  • Approved plugins: project-osmos and fabric-skills.
  • VS Code: Empty profile with only GitHub Copilot Chat installed.
  • Safety: interactive approvals; no broad auto-approval.

Confirm access

Install required software

Use the supported, minimal workstation components.

Install VS Code, Node.js, PowerShell 7, Git, Azure CLI, and GitHub Copilot CLI. Python is not a stated Project Osmos prerequisite.

node --version
npm --version
pwsh --version
git --version
az --version
copilot --version
npm install -g @github/copilot
copilot --version
3

Install ripgrep

Make rg available to the main CLI and subagent shells.

winget install BurntSushi.ripgrep.MSVC

Close and reopen PowerShell, then verify:

Get-Command rg
where.exe rg
rg --version
Start VS Code only after the new PowerShell session resolves rg. This lets VS Code inherit the updated process environment.
4

Create the workspace and clean profile

Isolate optional customizations, not foundational tools.

  1. Create a dedicated Osmos folder.
  2. In VS Code select File > Preferences > Profiles > New Profile.
  3. Name it Osmos Fabric Copilot Only.
  4. Choose Empty Profile.
  5. Choose None for Settings, Extensions, Keyboard Shortcuts, MCP Servers, Snippets, Tasks, and UI State.
  6. Use the profile for the current window and open the Osmos folder.
  7. Trust the workspace.
  8. Install only GitHub Copilot Chat from GitHub.
Expected: extensions and MCP servers from the Default profile do not appear. Copilot CLI plugins are managed separately.
5

Authenticate

Sign in before plugin validation.

Run GitHub Copilot: Sign In from the VS Code Command Palette. Then use an external PowerShell window:

az login
az account show
az account list --output table

If required:

az account set --subscription "<subscription ID or name>"
6

Install the approved plugins

Close VS Code first to avoid Windows file locks.

Close all VS Code, Copilot CLI, and Copilot desktop sessions before plugin installation.

Project Osmos

copilot plugin marketplace add microsoft/project-osmos
copilot plugin install project-osmos@project-osmos

Microsoft Fabric Skills

copilot plugin marketplace add microsoft/skills-for-fabric
copilot plugin install fabric-skills@fabric-collection
No trailing comma: use fabric-collection, not fabric-collection,.
copilot plugin marketplace list
copilot plugin list

9

Use a controlled first prompt

Keep routing narrow and approvals visible.

Use Project Osmos for this Microsoft Fabric data engineering task.

Before running anything:
1. Confirm the target workspace and Lakehouse from the full Fabric browser URL.
2. Identify whether the task is read-only or write-capable.
3. Show the planned steps.
4. Use Microsoft Fabric Skills for Fabric-specific APIs and conventions.
5. Ask before running commands or changing Fabric artifacts.
6. If an existing task exists in .dataprojects, resume it instead of creating a duplicate.

Do not use unrelated plugins, MCP servers, or custom agents.

Known targeted fixes

Avoid broad troubleshooting.

SymptomFix
Marketplace fabric-collection, not foundRemove the trailing comma.
Marketplace already registeredSkip marketplace add and run the install command.
Access denied, os error 5Close VS Code and Copilot sessions, then install from external PowerShell.
Fabric skills not visibleQuit/restart Copilot CLI and run /skills.
rg unavailable to a subagentInstall ripgrep system-wide, restart processes, verify in both shells.
Extra extensions/MCP serversConfirm the Empty Profile is active and inherited categories were set to None.
